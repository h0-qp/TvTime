## ✨ المميزات الرئيسية

- **واجهة مستخدم عصرية**: تصميم يعتمد على Material Design 3 و Jetpack Compose لتقديم تجربة بصرية سلسة.
- **تتبع الحلقات**: تتبع تقدمك في مشاهدة المسلسلات وقم بتعليم الحلقات التي شاهدتها.
- **قائمة المشاهدة**: أضف أفلامك ومسلسلاتك المفضلة إلى قائمة المشاهدة لتصل إليها بسرعة.
- **تفاصيل متكاملة**: احصل على معلومات مفصلة عن كل عمل، بما في ذلك التقييمات، طاقم العمل، والقصة.
- **بحث متقدم**: ابحث عن أي فيلم أو مسلسل بسهولة.
- **تزامن سحابي**: يعتمد على Firebase لمزامنة بياناتك وحفظ تقدمك بأمان.

## 🛠️ التقنيات المستخدمة

- **[Kotlin](https://kotlinlang.org/)**: لغة البرمجة الأساسية.
- **[Jetpack Compose](https://developer.android.com/jetpack/compose)**: لبناء واجهة المستخدم (UI).
- **[Coroutines & Flow](https://kotlinlang.org/docs/coroutines-overview.html)**: للبرمجة غير المتزامنة والتعامل مع البيانات.
- **[Retrofit](https://square.github.io/retrofit/)**: للتواصل مع واجهة برمجة التطبيقات (API).
- **[Firebase](https://firebase.google.com/)**: للمصادقة وتخزين البيانات.
- **[TMDB API](https://www.themoviedb.org/documentation/api)**: كمصدر رئيسي لبيانات الأفلام والمسلسلات.

## 🚀 البدء السريع

للبدء في تطوير التطبيق محلياً:

1. قم بعمل استنساخ (Clone) للمستودع:
   ```bash
   git clone https://github.com/your-username/TrackVerse.git
   ```

2. افتح المشروع باستخدام **Android Studio**.

3. احصل على مفتاح API من [TMDB](https://www.themoviedb.org/documentation/api) وأضفه إلى المشروع.

4. قم بتشغيل التطبيق على المحاكي أو جهاز حقيقي.
