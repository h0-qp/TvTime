## 📌 عن التطبيق
**TrackVerse** هو تطبيق أندرويد متكامل مصمم خصيصاً لعشاق الأفلام والمسلسلات. يتيح لك التطبيق استكشاف أحدث الأعمال الفنية، تتبع ما تشاهده، معرفة عدد الساعات التي قضيتها في المشاهدة، وبناء مكتبتك الخاصة من المسلسلات والأفلام المفضلة. تم بناء التطبيق باستخدام أحدث تقنيات تطوير الأندرويد (Kotlin & Jetpack Compose) لضمان تجربة مستخدم سلسة وعصرية.

## 🚀 الميزات الرئيسية

*   **🎬 قاعدة بيانات ضخمة (TMDB):** استكشاف ملايين الأفلام والمسلسلات مع تفاصيل كاملة (القصة، التقييمات، طاقم العمل، والمواسم).
*   **👤 نظام حسابات متكامل:** تسجيل الدخول عبر البريد الإلكتروني، حساب Google، أو المتابعة كضيف باستخدام (Firebase Auth).
*   **📊 إحصائيات المشاهدة:** تتبع دقيق لعدد الحلقات التي شاهدتها وإجمالي ساعات المشاهدة في ملفك الشخصي.
*   **❤️ قائمة المشاهدة (Watchlist):** إضافة الأعمال التي تنوي مشاهدتها أو التي تتابعها حالياً لسهولة الوصول إليها.
*   **🎨 واجهة سينمائية (Dark Mode):** تصميم ليلي عصري ومريح للعين بلمسات ذهبية جذابة (Cosmic Slate Theme).
*   **🔍 بحث متقدم:** محرك بحث سريع للبحث عن أي فيلم أو مسلسل أو ممثل بسهولة.
*   **⚙️ تخصيص الملف الشخصي:** إمكانية تعديل الاسم، النبذة الشخصية (Bio)، واختيار صور رمزية (Avatars) سينمائية.
*   **📱 تجربة مستخدم سلسة:** حركات وانتقالات (Animations) ناعمة لجميع العناصر والشاشات.

## 🛠️ التقنيات المستخدمة

*   **لغة البرمجة:** Kotlin
*   **واجهة المستخدم:** Jetpack Compose & Material Design 3
*   **قاعدة البيانات والمصادقة:** Firebase (Firestore, Auth)
*   **جلب البيانات (API):** Retrofit & TMDB API
*   **إدارة الحالة (State Management):** ViewModel & Kotlin Flows
*   **تحميل الصور:** Coil
*   **التنقل (Navigation):** Jetpack Navigation Compose (Type-safe)

## 📥 التثبيت والتشغيل

إذا كنت ترغب في تشغيل المشروع على بيئتك المحلية:

1. قم بعمل استنساخ (Clone) للمستودع.
2. افتح المشروع باستخدام **Android Studio**.
3. قم بإضافة مفتاح `TMDB_API_KEY` الخاص بك في ملف `local.properties` أو كمتغير بيئة.
4. قم بتشغيل التطبيق على محاكي (Emulator) أو هاتف أندرويد حقيقي.
